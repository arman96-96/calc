# ساخت خودکار APK از ماشین حساب PySide6

این پوشه یک ریپوی نمونه است که با GitHub Actions، بدون نیاز به هیچ تنظیمی روی سیستم خودتان، از `calculator.py` یک فایل APK می‌سازد.

## نحوه استفاده

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (خصوصی یا عمومی، فرقی ندارد).
2. کل محتوای این پوشه (شامل فایل `calculator.py` و پوشه `.github/workflows/`) را در ریپو push کنید:
   ```bash
   git init
   git add .
   git commit -m "افزودن ماشین حساب و ورک‌فلوی ساخت APK"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
3. به تب **Actions** در صفحه ریپو بروید. با پوش شدن روی شاخه `main`، ورک‌فلوی `Build Android APK` خودش شروع می‌شود (یا می‌توانید از همان تب دکمه **Run workflow** را برای اجرای دستی بزنید).
4. بعد از پایان اجرا (حدود ۱۵ تا ۳۰ دقیقه، بیشترش دانلود و نصب ابزارهای اندروید است)، در پایین صفحه‌ی همان اجرا بخش **Artifacts** را باز کنید و فایل `calculator-apk` را دانلود کنید — یک zip حاوی فایل `.apk` شماست.

## نصب روی گوشی
فایل apk را به گوشی اندرویدی منتقل کنید و نصب کنید (لازم است نصب از منابع ناشناس را در تنظیمات گوشی فعال کنید)، یا با adb:
```bash
adb install calculator.apk
```

## نکات مهم

- این ورک‌فلو فقط معماری **arm64-v8a** (رایج‌ترین معماری گوشی‌های امروزی) را می‌سازد. اگر به x86_64 هم نیاز دارید (مثلاً برای شبیه‌ساز اندروید)، یک job دوم مشابه با wheel های `android_x86_64` اضافه کنید.
- اگر برنامه‌تان به فایل دیگری غیر از `calculator.py` نیاز دارد (مثل آیکون یا فایل‌های کمکی)، آن‌ها را هم در ریپو قرار دهید؛ `pyside6-android-deploy` به‌صورت خودکار بسته‌بندی می‌کند.
- برای نسخه release قابل انتشار در Google Play (فایل aab) و امضای دیجیتال، تنظیمات بیشتری در `pysidedeploy.spec` لازم است که فراتر از این نمونه‌ی سریع است.
- زمان اجرای اولین بیلد بیشتر طول می‌کشد چون NDK/SDK دانلود و کش می‌شوند؛ می‌توانید با `actions/cache` این بخش را برای اجراهای بعدی سریع‌تر کنید.
